# Reference material

Source files used while building Traktor Touch FX. Not part of the mod.

- `traktor 4.x qml.zip` - stock QML folder from Traktor Pro 4 (property paths, screen files).
- `djmirror-main.zip` - DjMirror public repo snapshot.
- `DjMirror-v1.7.0-win-*.zip`, `DjMirror-v1.7.0-mac-*.zip` - DjMirror v1.7.0 mod packages.
